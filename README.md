# Week6_DataAnalytics_HealthConnect

The **HealthConnect Rwanda Data Analytics Project** is a healthcare Business Intelligence solution developed using **Power BI, SQL, and DAX** to analyze patient demographics, clinical outcomes, financial performance, healthcare operations, and patient satisfaction.

### Key Deliverables
- **Six-page Power BI dashboard** covering executive performance, patient analytics, clinical outcomes, financial performance, operational efficiency, and patient experience.
- **Data modeling and engineering** using a structured relational model, SQL data cleaning, and analytical queries.
- **Advanced analytics** with DAX measures, KPIs, time-based trends, and interactive visualizations.
- **Business reporting** translating healthcare data into actionable insights and recommendations.

### Key Insights
- Approximately **8 billion RWF in revenue** against **9 billion RWF in billings**.
- Insurance claim approval rate of **49.98%**, highlighting potential reimbursement delays.
- Reported **100% bed occupancy**, indicating pressure on inpatient capacity.
- Average patient satisfaction rating of **2.99/5**, identifying opportunities to improve patient experience.

### Business Recommendations
- Streamline insurance claims processing and follow-up.
- Review inpatient capacity and resource allocation.
- Improve service quality in departments with lower patient ratings.

**Tools:** Power BI · SQL · DAX · MySQL · Data Modeling · Data Visualization
